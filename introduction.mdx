CardVault is a personal inventory management system built for serious trading card collectors. It runs entirely on your local machine at [http://127.0.0.1:5000](http://127.0.0.1:5000), giving you full control over your collection data without relying on any third-party cloud service. Whether you're tracking raw cards, graded slabs, autographs, or serial-numbered parallels, CardVault keeps everything organized and priced in one place.

<Note>
  CardVault is a **local-only application**. It is not accessible from other devices on your network and stores all data on your own machine. No collection data is ever sent to an external server — the only outbound calls are optional eBay price lookups via the Apify API and AI features that use the Anthropic API.
</Note>

## What CardVault Does

CardVault covers every stage of managing a large personal collection:

- **Import from Excel** — Upload `.xlsm` workbooks to sync your inventory across 8 sports categories
- **Browse and search** — Filter by autograph, graded, rookie, relic, serial number, player, set, year, and more
- **Price cards** — Look up real eBay sold prices, apply bulk default value rules, and track value history over time
- **Manage collections** — Build curated subsets of your inventory and set collecting goals
- **Add card images** — Paste front and back scans using the Image Queue workflow
- **View analytics** — Dashboard summaries, Top 100 most valuable cards, and the CardVault 50 Index
- **Generate monthly reports** — AI-narrated snapshots of collection growth and value movement
- **Run a data audit** — 13 automated data quality checks with plain-English AI analysis
- **Look up grading population data** — Pull PSA, BGS, SGC, and CGC population data via GemRate
- **Supports a dark and light theme** — Switch between themes from any page

## Sports Categories

CardVault organizes your inventory into eight primary categories, each assigned a dedicated card ID range:

| Category | Card ID Range |
|---|---|
| Basketball | 1000000–1999999 |
| Hockey | 2000000–2999999 |
| Football | 3000000–3999999 |
| Baseball | 4000000–4999999 |
| Soccer | 5000000–5999999 |
| Dirk Nowitzki PC | 6000000–6999999 |
| Non-Sport | 7000000–7999999 |
| Multi-Sport / Other | 8000000–8999999 |

The **Dirk Nowitzki PC** category is a special player collection that lives within the Basketball sport but uses its own card ID range (6xxxxxx) so it can be imported and managed separately.
